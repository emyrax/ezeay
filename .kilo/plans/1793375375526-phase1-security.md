# Phase 1 — Security (ship blocker)

Scope: harden server before production. Phase 0 correctness done; deploy (Phase 2) and tests (Phase 3) follow.

## 1.1 Auth middleware wiring
- `requireAuth` exists (server/index.ts:325) but routes call `verifyClerkToken` inline. Keep inline (already consistent) but ensure EVERY route calls it. Audit: grep routes without verifyClerkToken; add to any missing (especially `/uploads` static, `/api/study/process`, enrollments, user-trophies).
- Store `claims.sub` on `req.userId` via middleware for cleaner ownership checks (optional refactor; do if touching routes).

## 1.2 IDOR fixes (user-scoped reads/writes)
- Reads by `?userId=`: courses, enrollments, user-trophies, study-materials must ignore client userId and filter by `claims.sub`.
- Writes: enrollments POST, user-trophies POST/check, course thumbnail must verify `claims.sub === body.userId`/owner.
- Pattern: replace `const userId = req.body.userId || req.query.userId` with `const userId = claims.sub`; reject mismatched with 403.
- Files: server/index.ts routes for enrollments, user-trophies, study-materials, courses (thumbnail already checks owner).

## 1.3 SSRF (`/api/study/process`)
- Validate URL: https only, hostname allowlist (own storage/CDN + known providers) OR block private IP ranges (10/127/169.254/::1) and disable redirects.
- Add fetch timeout (10s) and max response size (5MB). Abort on overflow.
- Reject non-URL / missing url with 400.

## 1.4 `/uploads` static hardening
- Option A (recommended): migrate to Cloudinary/Firebase Storage signed URLs — remove static serving entirely.
- Option B: gate behind auth token, allowlist extensions (png/jpg/webp/pdf), set `Content-Disposition: attachment`, `X-Content-Type-Options: nosniff`, path traversal guard.
- Remove user-controlled filename extensions; generate server-side UUID names.

## 1.5 Rate limiting, CORS, Helmet
- Add to server package: `express-rate-limit`, `helmet`, `cors`.
- Global limiter: 100 req/15min per IP (or per user via decoded sub).
- Stricter on AI/upload/create routes: 20 req/min.
- CORS allowlist from `CORS_ORIGINS` env (comma-separated); credentials true.
- Helmet defaults; CSP tuned for app needs.

## 1.6 Error sanitization
- `sendRouteError`: log full detail server-side (already w/ requestId), return only `{ error: "Internal server error", requestId }` for 5xx; surface 4xx messages as-is.
- Audit routes leaking `err.message` (search `res.status(500).json({ error: err.message })`); replace with generic.

## 1.7 Secrets hygiene
- Add `server/.env.example` listing all required/optional vars (GEMINI_API_KEY, CLERK_SECRET_KEY, NEON_DATABASE_URL, CORS_ORIGINS, optional OpenAI/Anthropic/OpenRouter, Cloudinary).
- Remove hardcoded Clerk publishable fallback in `app/_layout.tsx` (require env; fail fast in dev with clear error).
- Never log secrets.

## Validation
- `npm run test:server` (existing) + add smoke tests for auth (401 without token), IDOR (403 on cross-user), SSRF (400 on private IP).
- Manual: curl protected routes without token → 401; cross-user read → 403; upload non-image → 400.
